# 西洋音楽史｜復習と音源

## 内容

前期・後期を選び、マルバツ／4択の形式と授業回または全範囲を選択します。問題は毎回シャッフルされ、4択では選択肢も並べ替わります。正誤・正解、途中経過、終了時の正解率を表示します。前期の問題は元の questions.js（マルバツ250問、4択379問）をそのまま使用しています。

音源一覧は2026年度前期の指定スプレッドシートを基に作成しています。リンク付き51行のうち、同じ作品・作曲者・年代・リンクの重複をまとめた47件を表示します。作品名・作曲家・年代を検索できます。Naxosの各作品／トラックへ別タブで移動します。再生にはNaxos側の利用条件、ログインや所属機関の認証が適用される場合があります。現時点ではサイト内再生には対応していません。

## 開き方と GitHub Pages へのアップロード

1. `index.html` をブラウザで開くと確認できます。
2. サイト公開用には、少なくとも `index.html`、`style.css`、`script.js`、`questions.js`、`later-questions.js`、`listening.js` を同じ階層に配置します。
3. GitHub Pages の既存リポジトリに、これらのファイルを同じ階層で上書きアップロードします。従来と同じ Pages の公開先と設定を使います。
4. GitHub の反映に数分かかる場合があります。古い画面が表示されるときはブラウザを再読み込みしてください。

訪問カウンターは、元の index.html と同じ hits.sh の URL をそのまま使用しています。カウントは GitHub 内ではなく外部サービス側に保持されるため、同じカウンター URL のまま再アップロードすれば通常は継続します。表示・数値の保存は外部サービスの稼働状況や仕様に依存します。元の URL と異なるカウンターを既存の公開サイトで使っていた場合は、その URL を index.html の footer の img src に設定してください。

## 後期の問題を追加する

`second_truefalse.xlsx` と `second_multiple.xlsx` は、後期問題用の空のテンプレートです。前期の問題には影響しません。

- マルバツ：列は `出題範囲`、`問題文`、`正解`。正解は `○` または `×`。
- 4択：列は `範囲`、`問題`、`正解`、`誤答1`、`誤答2`、`誤答3`。4つの選択肢には異なる内容を入力。
- 出題範囲または範囲に `第1回` のような回数を含める（例：`第1回 古典派の音楽`）。両形式の回数は後期の授業回を指します。

2つの Excel ファイルを保存した後、ターミナルでこのフォルダを開いて、次のコマンドを実行します。初回に openpyxl が必要な場合は先にインストールしてください。

```bash
python3 -m pip install openpyxl
python3 convert_second_term.py
```

生成された `later-questions.js` を、他のサイトファイルと同じ場所にアップロードすれば後期の問題が反映されます。Excelファイル自体を公開する必要はありません。前期の `questions.js` はこのコマンドでは変更されません。

## 音源一覧の変更

`listening.js` 内の各項目は `title`（曲名）、`composer`（作曲者）、`date`（成立年代）、`url`（NaxosのURL）を含みます。`session` は元表の授業情報で、一覧は授業回で分割しません。スプレッドシートの更新が自動反映される仕組みではありません。
