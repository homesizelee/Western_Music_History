# 西洋音楽史 講義・復習ポータル

## サイトの構成

トップで前期または後期を選び、各学期の「復習問題」「授業資料」「音源リスト」に進みます。前期の問題629問・音源47件を引き継いでいます。後期の問題と音源は今後追加できます。問題のランダム出題、4択の選択肢のシャッフル、採点・途中経過・終了時の正解率を利用できます。

`index.html` をブラウザで開くと手元で確認できます。スマートフォンにも対応しています。

## 授業資料を使い始める（最初の１回）

このサイトは Google Drive の共有リンクを表示します。Google Drive の権限を自動設定するものではありません。資料のファイルやフォルダはまだ登録されていないので、先生自身が次の準備を行ってください。

1. 大学の Google アカウントの Google Drive に、前期用・後期用の授業資料フォルダを作成します。
2. 各フォルダに資料を入れ、フォルダの「共有」から一般的なアクセスを「制限付き」にしたうえで、受講生の大学 Google アカウント、または受講生の Google グループに「閲覧者」の権限を付けます。学内の全員やリンクを知っている全員に公開すると、受講者限定にはなりません。子ファイルにも意図した権限が適用されるか確認してください。
3. フォルダの共有リンクをコピーします。
4. このフォルダの `materials_setup.html` をダブルクリックして、Chrome 等のブラウザで開きます。
5. 「前期：フォルダの共有リンク」「後期：フォルダの共有リンク」にコピーしたリンクを貼り付けます。不要な学期は空欄でも構いません。
6. 「設定ファイルをダウンロード」をクリックします。ダウンロードされた `materials.js` を、このフォルダにある同名の `materials.js` に上書きしてください。
7. 同じフォルダの `index.html` を開き、該当学期 → 授業資料 → 「フォルダを開く」が表示されることを確認します。別のブラウザや学生アカウントで開き、許可した学生は閲覧でき、許可していないアカウントは閲覧できないかも確認してください。
8. サイトを GitHub Pages に反映するには、後述の「GitHubへのアップロード」を行います。

重要：サイトは Google アカウントでユーザーを認証しません。「フォルダを開く」や資料リンクを押すと Google Drive がアクセス権限を確認します。サイト上の授業名・リンク先は公開され得るため、パスワードや機密情報を設定画面に入力しないでください。

### 毎週の運用

フォルダのリンクを最初に登録した後は、その同じ Drive フォルダに新しいファイルを入れるだけで、学生は「フォルダを開く」から最新の内容を確認できます。ファイル追加だけなら GitHub の更新は不要です。フォルダ名や授業回ごとのファイル名を見て学生が探す方式です。

サイトの「第1回」「第2回」などの行に個別資料へのリンクを表示したい場合は、フォルダに資料を追加しただけでは自動登録されません。下の手順でその都度リンクも登録します。

### 授業回ごとのリンクを登録する（任意）

1. Google Drive で資料ファイルまたは授業回フォルダを共有し、共有リンクをコピーします。親フォルダの権限が適用されるか確認してください。
2. `materials_setup.html` を開き、「＋ 資料を追加」を押します。
3. 学期・回・授業名（任意）・資料名・共有リンクを入力します。例：後期／6／モーツァルト／レジュメ／Google Drive の共有リンク。
4. 複数の資料を同じ回に登録する場合は、同じ学期・回で行を追加します。
5. 「設定ファイルをダウンロード」を押し、生成された `materials.js` をこのフォルダの既存ファイルに上書きします。
6. ローカルで表示を確認してから、GitHub の同じ階層に `materials.js` を上書きアップロードします。

次回編集するときは、**前回生成した最新版の `materials.js` と同じフォルダにある** `materials_setup.html` を開いてください。古い `materials.js` のまま設定画面を開くと、以前登録した内容を消してしまう場合があります。

最初は各学期の第1〜15回を表示し、個別リンクのない回は「準備中」となります。16回以降のリンクも設定画面から追加できます。フォルダ内のファイル名やリンクは、設定画面に自動読み込みされません。

## GitHub へのアップロード

既存の GitHub Pages リポジトリに、次の８ファイルを同じ階層に置いてください。

- `index.html`
- `style.css`
- `script.js`
- `questions.js`
- `later-questions.js`
- `listening.js`
- `later-listening.js`
- `materials.js`

`materials_setup.html` と `materials_setup.js` は教員が自分のパソコンで設定を行うためのファイルです。GitHub へのアップロードは必須ではありませんが、手元には `materials.js` と一緒に保存してください。Excel テンプレート、変換スクリプト、README もサイト表示には不要です。既存サイトの他のファイルは必要に応じて残せます。

更新後、表示が古い場合はブラウザを再読み込みしてください。訪問カウンターは旧版と同じ外部サービスの URL を引き継いでいます。数値の継続・表示はそのサービスの仕様と稼働状況に依存します。

## 後期の問題を確認してから追加する

`second_truefalse.xlsx`（マルバツ156問）と `second_multiple.xlsx`（4択180問）には、第1〜6回の原稿を整理しています。４択の「正解」欄が正解、「誤答1〜3」が間違った選択肢です。難易度は0が一般問題、1が難問です。難易度は問題の抽出などのためExcelに保存し、サイトには表示されません。

これらの問題は**まだサイトに反映されていません**。正誤や内容を確認し、必要な修正を両方のExcelに保存してから、次の手順で反映してください。

1. ２つの Excel ファイルと `convert_second_term.py` を同じフォルダに置きます。
2. ターミナルでそのフォルダを開き、次を実行します。`openpyxl` のインストールは、まだ入っていない場合だけ必要です。

```bash
python3 -m pip install openpyxl
python3 convert_second_term.py
```

3. `later-questions.preview.js` が作成されます。この段階ではサイトの問題は変わりません。出題数と内容を確認し、実際に反映するときだけ次を実行します。

```bash
python3 convert_second_term.py --apply
```

4. `later-questions.js` が作成・更新されます。このファイルを他のサイトファイルと同じ階層に置き、GitHub にアップロードすると、後期問題が反映されます。以前の `later-questions.js` は上書きされるため、必要であれば事前にバックアップしてください。前期の `questions.js` は変更しません。

Excelの列名は次の通りです。出題回数には `第1回` のように記入します。難易度には必ず0または1を入力してください。

- マルバツ：`出題回数`、`問題文`、`正解`、`難易度`。正解は `○` または `×`。
- 4択：`出題回数`、`問題文`、`正解`、`誤答1`、`誤答2`、`誤答3`、`難易度`。４つの選択肢には異なる内容を入力。

問題のある行があれば変換を中止してファイル名と行番号を表示します。Excelの正解・誤答や難易度などの内容は担当教員が確認してください。Excelファイルを学生向けのGitHub公開フォルダに置く必要はありません。

## 音源一覧の変更

`listening.js` が前期、`later-listening.js` が後期の一覧です。後期用は空です。各項目は `title`（曲名）、`composer`（作曲者）、`date`（成立年代）、`url`（Naxos 等の URL）を含みます。スプレッドシートと自動同期する仕組みではありません。音源は外部サイトで開き、再生条件は各サイトの設定に従います。
